# 🚀 Getting Started

**Five minutes from install to your first logged swing.**

---

## 1 · Install & launch

Install Smart Trade on your Android device (Play Store release coming soon).
On first launch the **privacy screen** appears — read it and tap **I AGREE & CONTINUE**.

## 2 · Pick your mode

| Mode | What it is |
|---|---|
| **DEMO** (recommended first) | Paper wallet with live market prices — no real funds move |
| **LIVE** | Read-only Binance API key for real balances & exact fees |

Switch any time from `⚙ Settings → Mode`.

## 3 · (LIVE only) connect a key

1. `⚙ Settings → Binance API`
2. The app shows **your public IP** — copy it
3. Create an API key on the exchange with **Spot read/trade**, **no withdrawals**, and that IP whitelisted
4. Paste key + secret → **TEST & SAVE**

The key is encrypted in the device keystore the moment you save it.

## 4 · Choose a market

Tap the **pair name** (e.g. `SUI /USDT`) on the dashboard or chart — the coin selector opens:

- coins you hold worth **≥ 1 USDT** are listed first
- search any **coin/USDT** market
- chart, ticker and trading switch instantly

## 5 · Read the chart

- **1 finger** → crosshair (OHLC tooltip)
- **2 fingers** → pinch zoom + pan through history
- **−50 / +50** → quick zoom steps
- Intervals: `1m 5m 15m 1H 4H`

## 6 · Log a swing

- **BUY** / **SELL** buttons at the bottom
- Method 1: sell first → app arms a lower re-entry target
- Method 2: buy first → app arms a higher take-profit target
- Turn **Net target OFF** in Settings for fully manual journal trading — history still records

## 7 · Review

- **Account** → balances + profit/loss by date
- **History** → every completed cycle: entry, exit, fee, net profit, wallet snapshots
