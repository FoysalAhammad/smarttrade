# Smart Trade

Crypto swing trading journal for spot markets (USDT pairs).

## Features
- Live candlestick charts (1m–4H)
- Two swing methods (Sell-first / Buy-first)
- Auto targets with zone alerts
- Fee-aware P&L (auto-fetched Binance VIP fees)
- Multi-coin support (any USDT pair)
- Demo paper wallet
- Privacy-first: no accounts, no trackers, keys in Android Keystore
